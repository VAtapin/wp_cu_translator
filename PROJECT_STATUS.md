# Georg-Kloster Slavonic Translator — состояние проекта

## Реализовано

- Опубликованная 1.1.0 содержит переводчик и словарь AZBYKA_CU_FULL через Bible Desktop: поиск по слову/русскому значению, алфавит, пагинация, статья, источник и вставка в переводчик. Шорткоды: [wp_cu_translator], dictionary="no", [wp_cu_dictionary]. Настройки и Installation ID сохраняются.
- Форма следует текущему языку страницы WPML без фиксированного списка локалей и передаёт локаль в AJAX. Стандартный language pack имеет приоритет; встроенный каталог дополняет отсутствующие строки. Пользовательские заголовки зарегистрированы в wpml-config.xml.
- Исходные строки английские. В установочном ZIP сохранены 90 строк и полные RU/DE/UK/PL PO/MO. Каталоговый ZIP исключает PO/MO по требованию WordPress.org. Для импорта подготовлены 93 интерфейсные и 68 readme-строк на язык, включая журнал 1.1.1; проверка блокирует непереведённые новые записи журнала.
- Подготовлен кандидат 1.1.1 для проверки владельцем: Monomakh Unicode загружается из локального assets/fonts/ с SIL OFL 1.1; выбранная буква, варианты алфавита, словарные заголовки и результат перевода используют этот шрифт. Нет автоматической загрузки внешнего шрифта.
- Установочный georg-kloster-slavonic-translator-1.1.1-preview.zip содержит 22 файла и четыре перевода; кандидат для каталога — 14 файлов без PO/MO. Оба архива побайтно совпали с исходниками. Кандидат не опубликован.

## Причина английской формы и пределы исправления

- На https://georg-kloster.ru/kalendarnaya-masterskaya/ подтверждена уже установленная 1.1.0: asset ver=1.1.0, html lang=ru-RU и скрытая локаль формы ru_RU. HTML и JavaScript интерфейса оставались английскими.
- Стандартные georg-kloster-slavonic-translator-ru_RU.mo/.po/.l10n.php на сайте отвечают HTTP 404, тогда как русский каталог другого плагина Calendar отвечает HTTP 200. Отсутствие каталогов воспроизводит английский интерфейс при корректной русской локали. Предыдущее утверждение об устранении проблемы на сайте без проверки доставки пакета было преждевременным.
- На точном опубликованном 11-файловом плагине 1.1.0 без встроенных MO штатный Language_Pack_Upgrader скачал и установил RU пакет с downloads.wordpress.org/translation/plugin/georg-kloster-slavonic-translator/1.1.0/ru_RU.zip. HTML и JavaScript переводчика стали русскими. Это подтверждает загрузку стандартного пакета кодом опубликованной версии; автоматическое предложение обновления на сайте владельца ещё не проверено. Словарная надпись Dictionary и новое короткое описание остались английскими в самом пакете.
- Короткое описание 1.1.0 имеет новый оригинал и пока отсутствует в опубликованном языковом пакете; подробный readme переведён отдельно. Все четыре перевода нового короткого описания уже есть в исходных каталогах и установочном preview ZIP. Исправление публичной карточки требует последующего утверждения/доставки новых переводов WordPress.org.
- На основном сайте в авторизованной админке подтверждены ru_RU для сайта/пользователя, корректный slug и версия 1.1.0. После force-check нет предложения обновить переводы. Site Health: WordPress.org доступен, HTTP/TLS и фоновые обновления проходят, каталоги WordPress/plugins записываемы. Настройки WPML не менялись.
- На чистом prihod.georg-kloster.ru/?page_id=119 та же английская форма и 1.1.0; WPML среди активных плагинов отсутствует. В штатном plugins/update-check/1.1 JSON-запросе контрольный Calendar определяется и получает RU пакет, Translator отсутствует в plugins/no_update/translations. Минимальные заголовки, альтернативный/пустой PluginURI не меняют результат; исправление метаданных без доказательства не вносилось. Каталог показывает задержку выпуска на 6 часов (при проверке для 1.1.0 оставалось около 5). Это объясняет отсутствие предложения языкового обновления, но доступность после снятия задержки ещё нужно подтвердить.
- Владелец разрешил выпуск 1.1.1 и необходимых переводов. Установка ZIP с компьютера на его сайты запрещена; используются только штатные пакеты WordPress.org. В текущей диагностике сайт не обновлялся, переводы вручную в его файловую систему не копировались.
