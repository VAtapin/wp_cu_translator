# Georg-Kloster Slavonic Translator — состояние проекта

## Реализовано

- Подготовлена версия 1.1.0. Исправлена загрузка стандартных WordPress language packs: сначала используется wp-content/languages/plugins, затем встроенный каталог дополняет отсутствующие строки. При смене локали прежний text domain выгружается.
- Публичная форма следует текущему языку страницы WPML через документированные фильтры, без фиксированного списка языков. Локаль формы сохраняется в AJAX-запросах переводчика и словаря. Пользовательские заголовки зарегистрированы в wpml-config.xml.
- [wp_cu_translator] показывает переводчик и словарь во вкладках; dictionary="no" оставляет только переводчик. [wp_cu_dictionary] показывает отдельный словарь. Административная справка, README и описание обновлены.
- Словарь использует настоящий Bible Desktop API AZBYKA_CU_FULL: поиск по слову/гражданскому написанию, русскому толкованию, исходному разделу, пагинация, полная статья и ссылка на Азбуку. Словарную форму можно вставить в переводчик без автоматического перевода; выбранное слово результата можно искать в словаре. Морфология, аудио и автоматическое исправление перевода не реализованы.
- Словарные запросы выполняются после действий посетителя, проходят nonce/валидацию и существующий HTTPS/TLS транспорт без перенаправлений. Ответы кэшируются пять минут; удалённый текст выводится как текст, ссылки ограничены HTTPS. Контракт backend: BibleDesktop/docs/CHURCH_SLAVONIC_DICTIONARY_API.md, commit 6d5f1d7.
- Сохранены 90 английских исходных строк и четыре полных каталога RU/DE/UK/PL. Для WordPress.org подготовлены 93 строки интерфейса и 66 строк описания на язык. Установочный ZIP 1.1.0 содержит 19 файлов, каталоговый ZIP — 11 без PO/MO.
- Для каждого выпуска журнал изменений переводится на RU/DE/UK/PL. Генератор сверяет все changelog-записи readme с исходным каталогом; новая непереведённая запись блокирует выпуск. Проверка включена в release/SVN workflow. Положительная проверка воспроизводимости и пять отрицательных случаев (новая строка вне каталога и пропущенный перевод в каждой локали) прошли; actionlint прошёл. Подготовка переводов не подменяет импорт/утверждение и проверку локализованной страницы каталога.
- Прозрачные иконки 128/256 и runtime PNG подготовлены из утверждённого логотипа, угловые пиксели alpha 0. Каталоговые иконки опубликованы из commit 5250813: Actions run 38413978511 success, icon SVN revision 3744193. Публичные CDN-файлы с ревизией страницы совпали побайтно. Runtime PNG входит в следующую версию.
- Владелец утвердил русский баннер по образцу другого своего плагина: зелёное поле, золотая рамка/орнамент, знак переводчика с книгой, русский заголовок и подпись. Подготовлены локализованные banner-772x250-ru_RU.png / banner-1544x500-ru_RU.png; размеры, лимит 4 MB и читаемость проверены. Английский fallback сохранён. Assets workflow по умолчанию сохраняет опубликованный SVN readme, чтобы отдельно публиковать изображения при ещё не выпущенной 1.1.0; actionlint прошёл. Публикация из commit 459746b прошла: Actions run 38426388209 success. Оба русских баннера SVN/CDN побайтно совпали с исходниками; опубликованные readme и PHP в trunk и tags/1.0.9 побайтно сохранены. Публичная RU-страница пока выбирает прежний английский баннер: локализованные файлы доступны в CDN, обновление метаданных страницы ещё не подтверждено. Имена ru_RU проверены по официальному коду импортёра и выбора локали WordPress.org; повторная публикация файлов не нужна.
