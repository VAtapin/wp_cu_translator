# Georg-Kloster Slavonic Translator — состояние проекта

## Реализовано и решения

- Версия 1.0.6; имя `Georg-Kloster Slavonic Translator`, slug/text domain `georg-kloster-slavonic-translator`.
- Все исходные строки интерфейса, метаданные и встроенные примеры шорткодов — английские (en_US). Полные каталоги 63 строк RU/DE/UK/PL сохранены; английский работает без каталога перевода.
- Оба ZIP и WordPress.org deploy workflow сохраняют все четыре PO/MO и POT по требованию владельца. Установочный и WordPress.org ZIP имеют одинаковое содержимое. Это заменяет прежнее исключение PO/MO из WordPress.org-пакета.
- Сохранены `[wp_cu_translator]`, пользовательские заголовки, options и Installation UUID. Языки интерфейса не меняют поддерживаемые API исходные языки текста RU/DE/auto.
- Бесплатный API Bible Desktop работает без ключа. Сохранён необязательный серверный ключ для повышенных лимитов; HTTPS, TLS, запрет перенаправлений и ограничения доступа не менялись.
- В readme и форме раскрыта внешняя обработка текста, возможное OpenAI и прямые ссылки на опубликованные условия/политику Bible Desktop.
- Репозиторий `VAtapin/wp_cu_translator`, main → origin/main. Тег версии запускает проверку и GitHub Release с установочным ZIP, alias ZIP и WordPress.org ZIP. Публикация в каталоге WordPress.org требует отдельного одобрения.
- По скриншоту владельца 11 октября 2026 заявка 1.0.5 отправлена, slug назначен, статус Awaiting Review. Новая заявка не нужна: архив 1.0.6 следует загрузить кнопкой Upload updated.

## Проверки 11 октября 2026

- PHP lint runtime/uninstall/двух smoke-тестов и JavaScript syntax прошли (локальный PHP 8.4.25).
- Генерация всех четырёх каталогов воспроизводима. Регрессии подтверждают отклонение кириллицы в PHP-исходнике, неверных placeholders и пустых переводов; эти проверки добавлены в release CI.
- Изолированный WordPress/SQLite: EN/RU/DE/UK/PL, все 63 строки каждого каталога, метаданные, frontend HTML/JS, custom heading, активация и сохранение settings/UUID прошли. Во время активации внешние запросы запрещены тестом.
- Официальный Plugin Check: `No errors found`. Тестовая среда выводила notices из-за отсутствующей темы; findings плагина нет.
- Публичные юридические страницы проверены без cookies; реальные запросы через код плагина без ключа: status HTTP 200, библейская ссылка HTTP 200 (corpus), обычный текст HTTP 200 (ai). Режим с ключом отдельно не проверялся.
- Оба ZIP содержат один правильный корневой каталог, 14 runtime/catalog файлов, без тестов, Git и секретов. Каждый файл побайтно сравнен с исходником. SHA-256 обоих локальных ZIP: `AA215D3767A28794C291976D80C80EE9E83567B6FC304C0EB0993BBDE54B0F0B`.
