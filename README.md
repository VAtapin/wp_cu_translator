# Church Slavonic Translator

WordPress-плагин для перевода русского и немецкого текста на церковнославянский язык через [Bible Desktop](https://bible-desktop.com/).

Плагин работает сразу после активации через бесплатный публичный режим Bible Desktop и не содержит OpenAI API key. Браузер отправляет текст в WordPress, а WordPress выполняет серверный запрос к Bible Desktop. Необязательный ключ Bible Desktop API включает повышенные лимиты и не попадает в HTML или JavaScript страницы.

## Установка

После следующего подтверждённого GitHub Release установочный архив будет доступен как `church-slavonic-translator.zip`. До этого используйте локально проверенный ZIP из сборки проекта.

1. В WordPress выберите **Плагины → Добавить новый → Загрузить плагин** и загрузите `church-slavonic-translator.zip`.
2. Активируйте **Church Slavonic Translator** — бесплатный режим уже готов к работе.
3. При необходимости повышенных лимитов создайте ключ в **Bible Desktop → Система → ИИ-интеграция → Подключение внешних сайтов** и сохраните его в **Настройки → Church Slavonic Translator**.
4. Нажмите **Проверить соединение**. Проверка не вызывает OpenAI и не расходует деньги.
5. Добавьте на страницу шорткод `[wp_cu_translator]`.

Требования: WordPress 6.3 или новее, PHP 8.0 или новее, HTTPS-доступ к `bible-desktop.com`.

## Использование

Основной шорткод:

```text
[wp_cu_translator]
```

С собственным заголовком:

```text
[wp_cu_translator title="Перевод на церковнославянский"]
```

Форма поддерживает русский, немецкий и автоматическое определение языка, а также ударения, титла, придыхания и славянскую запись чисел. Результат можно скопировать как обычный текст или как форматированный HTML для Word. Ссылка на Monomakh Unicode доступна рядом с результатом.

Название и описание плагина, страница настроек, сообщения и публичная форма доступны на английском, русском и немецком. Язык выбирается автоматически по локали WordPress; отдельный переключатель не требуется.

## Расходы и безопасность

- Библейская ссылка, точный стих или уверенно распознанная цитата обслуживаются локальным корпусом Bible Desktop без OpenAI.
- Повторный запрос с теми же параметрами может обслуживаться кэшем.
- Остальные тексты используют общую модель и лимиты, настроенные владельцем Bible Desktop. Бесплатный режим ограничен по числу реальных ИИ-вызовов и обрабатываемых символов.
- При первой активации создаётся постоянный Installation ID (UUID). Это идентификатор установки, а не секрет; он нужен для учёта бесплатной квоты.
- Необязательный внешний ключ хранится только в WordPress options и передаётся исключительно серверу Bible Desktop по HTTPS.
- HTTP, перенаправления внешнего запроса и отключение проверки TLS не разрешены.
- Для минутного лимита передаётся необратимый HMAC-идентификатор посетителя; его IP не отправляется в Bible Desktop. Суточная ИИ-квота считается на Installation ID.

## Разработка и выпуск

Номер версии должен совпадать в заголовке `church-slavonic-translator.php`, `readme.txt` и Git-теге. Тег версии запускает GitHub Actions, который:

1. проверяет версии и синтаксис PHP/JavaScript;
2. проверяет и пересобирает каталоги переводов;
3. собирает архивы `church-slavonic-translator-1.0.0.zip` и `church-slavonic-translator.zip`;
4. создаёт GitHub Release с обоими файлами.

Публикация в WordPress.org отключена, пока переменная репозитория `WORDPRESS_ORG_ENABLED` не получит значение `true` и не будут настроены секреты `SVN_USERNAME` и `SVN_PASSWORD`.

## Проверка по замечаниям WordPress.org — 7 октября 2026

Проверены категории из письма о другом плагине: название, принадлежность автору, переводы, внешние сервисы и права публичных обработчиков. Письмо не является результатом проверки этого плагина, а успешный Plugin Check сам по себе не гарантирует одобрения каталога.

- **Название:** `Church Slavonic Translator` описывает функцию, но не содержит отличительного бренда. Поиск не подтвердил одноимённый плагин WordPress.org, однако это не доказывает уникальность или отсутствие прав третьих лиц. Рекомендуется согласовать `Atapin Church Slavonic Translator` / `atapin-church-slavonic-translator` до подачи; имя и slug пока сохранены. При переименовании нужно согласованно обновить заголовок, readme, text domain, каталоги переводов, сборку, deploy workflow и smoke-тест. Если заявка уже подана, смену slug согласуют с Plugins Team.
- **Принадлежность:** `Author` — Vladimir Atapin, `Author URI` — `atapin.de`, а `Plugin URI` указывает на `kalender.georg-kloster.ru`. Kalendar документирует DNS-подтверждение `wordpressorg-atapin-verification`: оба авторитетных сервера `atapin.de` согласованы, для `georg-kloster.ru` на момент предыдущей проверки оставалось расхождение. При запросе ревьюера следует пояснить связь автора с доменами и Bible Desktop; DNS в этой задаче не менялся.
- **Внешние сервисы:** `readme.txt` уточняет момент отправки текста, все специальные заголовки, различия между переводом и проверкой соединения, ручную загрузку шрифта, изменение API URL и возможную передачу текста в OpenAI. Прямые документы Bible Desktop найдены в Kalendar и BibleDesktop: `/pages/api-terms` и `/pages/api-privacy`. Их исходные тексты описывали календарный API и исключали ИИ. В BibleDesktop добавлены разделы перевода, UUID/HMAC, OpenAI, кэша и квот и команда идемпотентного расширения CMS. Условия уже дополнены через CMS; сохранение политики ожидает явного подтверждения публикации после блокировки автоматической проверкой. Ссылки OpenAI дополняют, но не заменяют документы Bible Desktop.
- **Переводы:** PO/MO включены намеренно для установки ZIP вне WordPress.org. Замечание письма о них — рекомендация использовать translate.wordpress.org, а не доказательство нарушения. После появления утверждённых переводов в каталоге можно исключить локальные PO/MO из WordPress.org-пакета, сохранив их для GitHub ZIP; сейчас переводы не удалены.
- **Права:** `register_rest_route()` и `wp_register_ability()` не используются. AJAX-перевод намеренно доступен посетителям, включая гостей, и проверяет nonce, язык и размер текста. Nonce не является авторизацией или защитой от исчерпания квоты: её должен обеспечивать API Bible Desktop. Публичный перевод использует общий ключ и квоту установки, если ключ настроен; это должно быть сознательным выбором администратора. Настройки защищены `manage_options` и Settings API; проверка соединения — `manage_options` и nonce. Installation ID и HMAC используются для квот, а ключ не выводится в браузер.
- **Запросы и вывод:** сервер использует `wp_safe_remote_request`, HTTPS при сохранении настроек, проверку TLS и запрет перенаправлений; ввод очищается, HTML экранируется, результат в браузере выводится через `textContent`. Автоматических запросов внешнему сервису при активации или показе формы нет.

Перед подачей дополнительно проверить настоящий перевод и лимиты бесплатного/ключевого режимов, пройти актуальный Plugin Check и проверить окончательный ZIP. В рамках этой проверки production API не вызывался, письмо WordPress.org не отправлялось, DNS/аккаунт не менялись, релиз и deployment не выполнялись.
